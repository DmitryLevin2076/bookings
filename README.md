# Бронирование переговорной

Тестовое задание на React, TypeScript и Vite. Приложение показывает расписание одной переговорной и позволяет управлять бронями. Рабочий день с 09:00 до 18:00, даты и время в интерфейсе указаны в UTC.

## Как запустить

Понадобятся Node.js 22.12 или новее и npm. Выполни из корня проекта:

```bash
npm install
npm run dev
```

Открой локальный адрес, который Vite выведет в терминале. MSW запускается вместе с приложением.

Чтобы проверить собранную версию, выполни:

```bash
npm run build
npm run preview
```

## Что сделано

**Часовой пояс.** Даты и время в интерфейсе, рабочие часы `09:00–18:00` и проверка прошедшего времени используют **UTC (UTC+0)**. При создании и редактировании вводите время по UTC. Например, `10:00` в форме соответствует `14:00` по местному времени в UTC+4.

- Выбор даты и список броней по времени начала. По умолчанию открывается текущая дата по UTC.
- Создание, редактирование с переносом на другой день и удаление с подтверждением.
- Проверка рабочего времени, длительности от 30 до 120 минут и пересечений. Соседние брони могут касаться границ. Прошедшее время недоступно для бронирования, а начавшиеся брони защищены от редактирования и удаления.
- Обработка конфликта `409`. Список броней на выбранный в форме день обновляется, а введенные данные сохраняются.
- Состояния загрузки, пустого списка, ошибки и отправки формы. При ошибке загрузки запрос можно повторить.
- Запросы вынесены из компонентов. MSW имитирует API для получения, создания, изменения и удаления броней.

## Что не сделано

- Реальный бэкенд и база данных. В рамках задания API имитирует MSW.
- Постоянное хранение броней и синхронизация между вкладками. Данные хранятся в памяти и сбрасываются после перезагрузки страницы.
